### Лабораторная работа по курсу "Разработка игр"

Выполнил: Киселев А.О.

Группа: М8О-403Б-22

### Описание

3D-головоломка от первого лица с реалистичной оптикой.
Цель игры:
Провести лучи света от источников до приёмников,
используя зеркала, цветные фильтры и призмы, чтобы открыть выход из комнаты.
Три ключевые игровые механики
1. Субтрактивное смешение цветов через фильтры
Игрок может устанавливать на пути лучей полупрозрачные
цветные фильтры (Cyan, Magenta, Yellow).
Каждый фильтр вычитает определённую компоненту из спектра света:
Cyan → поглощает красный, пропускает зелёный + синий
Magenta → поглощает зелёный, пропускает красный + синий
Yellow → поглощает синий, пропускает красный + зелёный.
Лучи разных цветов могут аддитивно смешиваться в одной
точке (например, красный + зелёный = жёлтый).
Это позволяет получать цвета, которых нет в исходных источниках.

2. Преломление света с дисперсией в призме
Игрок вращает треугольную призму, изменяя угол преломления
проходящего луча по закону Снеллиуса. При попадании белого
луча в призму происходит дисперсия — луч расщепляется
на RGB и CMY  составляющие, каждая
из которых отклоняется на свой угол.
Это позволяет направлять лучи в труднодоступные места
и выделять нужные спектральные компоненты.

3. Селективное отражение от "умных" зеркал
В игре присутствуют цвето-селективные зеркала:
Красное зеркало отражает только красный свет, остальные
цвета пропускает
Зелёное зеркало отражает только зелёный
Синее зеркало отражает только синий
Это позволяет разделять смешанные лучи на компоненты или, наоборот,
собирать лучи разных цветов с разных направлений в один приёмник.


Также сделаны дополнительные механики для передвижения по карте, перемещения некоторых объектов,
чтобы можно было навести луч в нужную точку.

Управление объектами
Взять/бросить:

ЛКМ — взять объект, на который смотрите

ЛКМ (когда держите) — бросить объект

Расстояние:

Колёсико мыши — приблизить/отдалить объект

Вращение:

Q/E — поворот влево/вправо

R/F — наклон вверх/вниз

T/G — вращение вокруг своей оси

V — сбросить вращение (повернуть к себе)

Визуальные подсказки:

Жёлтый — можно взять

Розовый — держите в руках

Условия:

Объект должен иметь тег "Interactable"

Объект должен иметь Collider
